= Red Hat OpenShift Virtualization 資料收集器
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
DII Promox 虛擬環境收集器將收集庫存資料。這是一個基於 HTTPS REST API 的收集器。



== 術語

對於Data Infrastructure Insights所取得的每種資產類型，都會顯示該資產最常用的術語。當查看或排除此資料收集器的故障時，請記住以下術語：

[cols="2*"]
|===
| 供應商/型號術語 | Data Infrastructure Insights術語 


| 磁碟 | 虛擬磁碟 


| 主持人 | 主持人 


| 虛擬機 | 虛擬機 


| 儲存域 | 資料儲存 


| 邏輯單元 | 邏輯單元號 
|===
注意：這些只是常見的術語映射，可能並不代表此資料收集器的所有情況。



== 配置

[cols="2*"]
|===
| 場地 | 描述 


| 主機名稱或 IP 位址 | 儲存系統的主機名稱 IP 位址 


| API 權杖 ID | 存取需要 API Token 


| API Token 秘密金鑰 | 上述令牌的秘密 
|===


== 進階配置

[cols="2*"]
|===
| 場地 | 描述 


| HTTPS 通訊埠 | 用於 HTTPS 通訊的連接埠（預設 8006） 


| 庫存輪詢間隔（分鐘） | 預設值為 20 分鐘。 
|===
