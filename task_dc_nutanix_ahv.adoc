= Nutanix AHV 資料收集器
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Nutanix AHV 收集器使用 Prism Central v4 REST API（叢集管理和虛擬機器管理命名空間）從 Nutanix Prism Central 取得 Nutanix Acropolis Hypervisor (AHV) 清單和虛擬化效能資訊。它以虛擬化 OData 模型（VirtualizationRoot 以及相關實體：主機、虛擬機器、資料儲存、虛擬磁碟和關聯）報告資料。



[[terminology]]
== 術語

[cols="50,50"]
|===
| 供應商/型號術語 | Data Infrastructure Insights術語 


| AHV 節點（主機） | 主持人 


| Prism Central 叢集 | 虛擬機器管理程式（虛擬伺服器） 


| Acropolis VM | 虛擬機 


| 儲存容器 | 資料儲存 


| ADSF Volume Group | 邏輯單元號 


| 虛擬機器磁碟 | 虛擬磁碟 
|===
注意：這些只是常見的術語映射，可能並不代表此資料收集器的所有情況。



[[requirements]]
== 要求

* Prism Central IP 位址或完全限定域名
* Prism Central 本機或 LDAP 使用者名稱和密碼（唯讀帳戶即可）
* 連接埠要求：HTTPS 9440
* Prism Central 版本 pc.2023.x 或更高版本（v3 API）；建議使用 pc.7.x 或更高版本（v4 API）
* 效能計量需要 Prism Central 搭配 API v4.0.b1 或更新版本（pc.7.3+）。在舊版本中，系統會收集庫存資訊，但不會報告效能資料。

[[advanced-configuration]]
== 進階配置

[cols="50,50"]
|===
| 場地 | 描述 


| TCP 連接埠 | 用於連接 Prism Central 的 TCP 連接埠。預設值為 9440。 


| 庫存輪詢間隔（分鐘） | 庫存輪詢間隔時間。預設值為 60 分鐘。 


| 效能輪詢間隔（秒） | 效能輪詢間隔。預設值為 300 秒。 


| HTTP 逾時時間（秒） | HTTP 請求逾時時間。預設值為 60。 


| HTTP 重試次數 | 瞬態故障時的 HTTP 重試次數。預設值為 3。 
|===
