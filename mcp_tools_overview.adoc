[role="lead"]
DII MCP 伺服器目前在九個網域中公開了 26 個唯讀產品工具。當連線的用戶端需要進行驗證時，可能會出現一個分隔的 +mcp_auth+ 輔助程式。


NOTE: DII MCP 是一項 link:concept_preview_features.html["預覽"] 功能，因此可能會發生變化。

工具的可用度和結果取決於已驗證的租戶、已啟用的 DII 功能、已設定的收集器和使用者權限。



[[query-conventions]]
== 查詢約定

* 在查詢動態欄位之前，先探索類型和中繼資料。
* 使用中繼資料傳回的精確、區分大小寫的屬性和指標名稱。
* 必要時使用 ISO-8601 時間戳記和 IANA 時區名稱。
* 將查詢視窗保持在 30 天或更短。
* 使用 `limit`和 `offset`進行物件和警報分頁。
* 使用傳回的游標進行日誌事件分頁。
* 請勿顯示完整的 webhook 端點位址。

[[alerts]]
== 警報



[[get-alert-metadata]]
=== 取得警報中繼資料

+AlertsService_getMetadata+

傳回有效的警示欄位名稱和資料類型。請在查詢警示之前呼叫此項目。



[[query-alerts]]
=== 查詢警報

+AlertsService_queryForAlerts+

查詢具有選定屬性、篩選器、排序、時間範圍和偏移分頁的作用中或非作用中警示。

必要輸入：

* `active`
* `attributeNames`
* `fromTime`
* `toTime`
* `timezone`


可選輸入包括 `filter`、 `sortField`、 `sortAscending`、 `limit` 和 `offset`。 `limit` 為 1-500； `offset` 為 0-1000。將時間範圍保持在 30 天以內。

範例：

[]
====
檢索過去七天內的關鍵作用中儲存設備警報。傳回警報 ID、監控名稱、嚴重性、狀態和相關儲存設備名稱。

====


[[get-an-alert-by-name]]
=== 按名稱取得提醒

+AlertsService_getAlertByName+

使用 `AL-123456` 格式的警報 ID 擷取一則警報。

必填輸入： `name`



[[get-an-alert-by-uuid]]
=== 透過 UUID 取得警報

+AlertsService_getAlertByUUID+

使用其 UUID 擷取一個警報。

必填輸入： `uuid`

將此工具用於輪詢間隔、設定的計量、收集設定或故障調查。



[[list-supported-data-source-types]]

+CollectorService_getDataSourceTypes+

[[logs]]
== 紀錄



[[list-log-types]]
=== 列出日誌類型

+LogService_getLogTypes+

列出租戶中目前可用的日誌類型。



[[get-log-type-metadata]]
=== 取得日誌類型中繼資料

+LogService_getLogTypeMetadata+

傳回指定日誌類型的有效屬性。請在搜尋或分組事件之前呼叫此函數。

必填輸入： `type`



[[query-log-events]]
=== 查詢日誌事件

+LogService_queryLogEvents+

以時間戳記遞減順序傳回日誌事件。

必要輸入：

* `type`
* `fromTime`
* `toTime`
* `timezone`


選用輸入包括 `attributes`、 `filter`、 `limit`及 `cursor`。 `limit` 為 1-200。事件視窗不能超過 30 天。傳遞上一個回應的游標以擷取下一頁。



[[count-log-events-over-time]]
=== 統計一段時間內的日誌事件

+LogService_queryLogEventsCountHistogram+

傳回固定大小的事件計數時間段。可以選擇性地依有效的分組屬性對每個時間段進行分組；分組結果會傳回前幾個區段以及一個 +__other__+ 區段。

必要輸入：

* `type`
* `fromTime`
* `toTime`
* `timezone`


選用輸入： `filter`， `groupBy`

[[objects-and-metrics]]
== 物件和計量



[[list-object-types]]
=== 列出物件類型

+ObjectService_getObjectTypes+

列出租戶中目前可用的物件類型。



[[get-object-metadata]]
=== 取得物件中繼資料

+ObjectService_getMetadataForObjectType+

傳回一種物件類型的有效屬性、計量、類型和分組功能。

必填輸入： `objectType`



[[query-objects]]
=== 查詢物件

+ObjectService_query+

擷取物件、選定的屬性和選用的計量。參照計量的篩選器會套用至時間視窗集合體之前的原始值。

必要輸入：

* `objectType`
* `attributeNames`


選擇性輸入包括 `metricNames`、 `filter`、 `sortFieldName`、 `isSortAscending`、 `fromTime`、 `toTime`、 `aggregateFunctions`、 `limit`及 `offset`。

支援的查詢集合體： `MAX`， `MIN`， `AVG`， `SUM`， `LAST`。 `limit` 為 1-500。如果省略時間範圍，則工具預設使用最近三個小時的時間視窗。



[[group-objects]]
=== 群組物件

+ObjectService_groupObjects+

根據一個有效的可分組屬性對物件進行分組，並聚合選定的計量。篩選器在集合體之前應用於原始值。

必要輸入：

* `objectType`
* `groupByAttribute`
* `metricNames`


可選輸入包括 `aggregateFunctions`、 `filter`、排序、時間範圍、 `limit`及 `offset`。

支援的群組集合體： `MAX`， `MIN`， `AVG`， `SUM`， `FIRST`， `CHANGE`，+CHANGE_RATIO+。



[[query-performance-time-series]]
=== 查詢效能時間序列

+ObjectService_queryPerformanceMetricsForObjects+

傳回一個計量及相符物件的分桶時間序列資料。

必要輸入：

* `objectType`
* `metricName`
* `fromTime`
* `toTime`
* `timezone`


選用輸入包括 `filter`、 `aggregationFunction`、 `limit`和 `isSortAscending`。 `limit`控制傳回序列的數量，必須為 1-50。

支援的 bucket 集合體： `MAX`、 `MIN`、 `AVG`、 `SUM`、 `FIRST`、 `CHANGE`、+CHANGE_RATIO+。

[[filter-operators]]
== 過濾營運者

告警、日誌和物件查詢支援巢狀條件：

* `EQ`, `NE`
* `GT`, `LT`, `GE`, `LE`
* `WILDCARD`使用 `++*++`和 `?`
* `EXISTS`
* 巢狀 `and`、 `or`和 `not`


連接的伺服器會根據中繼資料驗證欄位。如果查詢被拒絕，重新整理相關中繼資料並重建篩選器。
