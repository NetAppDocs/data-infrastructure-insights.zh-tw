= 關於儲存工作負載安全
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Data Infrastructure Insights 儲存工作負載安全性（原 Cloud Secure）利用先進的內部威脅偵測和可操作的情報來保護您組織的資料。獲得跨混合雲環境所有企業資料存取的集中可見度與控制，同時透過即時監控與自動化回應功能，確保達成安全性與法規遵循目標。



[[visibility]]
== 能見度

取得對使用者存取本機或雲端中儲存的關鍵公司資料的集中可見性和控制。

替換無法及時準確地提供資料存取和控制可見性的工具和手動流程。工作負載安全且獨特地在雲端和本地儲存系統上運行，為您提供惡意使用者行為的即時警報。



[[protection]]
== 保護

透過先進的機器學習和異常檢測保護組織資料不被惡意或受感染的使用者濫用。

透過先進的機器學習和使用者行為異常檢測，向您發出任何異常資料存取警報。



[[compliance]]
== 遵守

透過審核用戶對儲存在本地或雲端中的關鍵公司資料的存取來確保公司合規性。
