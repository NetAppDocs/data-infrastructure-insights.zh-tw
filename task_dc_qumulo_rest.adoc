= Qumulo REST 資料收集器
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Data Infrastructure Insights 使用此收集器從 Qumulo 儲存設備取得庫存和效能資料。



== 術語

Data Infrastructure Insights從該數據收集器獲取以下庫存資訊。對於Data Infrastructure Insights取得的每種資產類型，都會顯示用於該資產的最常用術語。當查看或排除此資料收集器的故障時，請記住以下術語：

[cols="2*"]
|===
| 供應商/型號術語 | Data Infrastructure Insights術語 


| 駕駛 | 磁碟 


| 簇 | 儲存 


| 節點 | 儲存節點 


| OneFS 檔案系統 | 內部體積 


| OneFS 檔案系統 | 儲存池 


| qtree | qtree 
|===
注意：這些只是常見的術語映射，可能並不代表此資料收集器的所有情況。



== 要求

您需要以下資訊來設定此資料收集器：

* 用戶帳戶和密碼。此帳戶不需要是管理員/root，但您必須向您的服務帳戶授予大量唯讀權限 - 請參閱下表
* Qumulo 叢集的 IP 位址 / 完全限定域名
* HTTPS 存取連接埠 8080




== 配置

[cols="2*"]
|===
| 場地 | 描述 


| Qumulo IP 位址 | Qumulo 儲存設備的 IP 位址或完整網域名稱 


| 使用者名稱 | Qumulo 的使用者名稱 


| 密碼 | 用於 Qumulo 的密碼 
|===


== 進階配置

[cols="2*"]
|===
| 場地 | 描述 


| HTTPS 連接埠 | 預設值為 8080。 


| 庫存輪詢間隔（分鐘） | 庫存輪詢之間的時間間隔。預設值為 30。 


| 效能輪詢間隔（分鐘） | 效能輪詢之間的時間間隔。預設值為 5。 
|===
