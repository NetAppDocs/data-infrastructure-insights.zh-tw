= 刪除工作負載安全代理
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
當您停用其主機或將收集作業合併到另一個代理程式時，請刪除代理程式。刪除代理程式也會刪除所有仍指派給它的收集器。

[cols="100%"]
|===
| *刪除代理程式會同時刪除其剩餘的收集器* 任何仍指派給該代理程式的資料收集器或 User Directory Collector 都會隨之移除，且組態無法復原。請在刪除代理程式之前記錄或移動您仍然需要的任何組態。 
|===


[[decide-what-you-want-to-keep]]
== 決定您要保留的內容

[cols="37%,63%"]
|===
| *您的目標* | *處置方式* 


| 持續從另一個代理程式收集相同的儲存設備 | 在刪除此代理程式之前，請將每個收集器移至另一個代理程式。重新指派收集器而不是重新建立它們，以免收集重複。 


| 完全停止從此儲存設備收集 | 刪除代理程式。仍指派給它的收集器也會同時刪除。 


| 在新主機上重建代理程式 | 首先記錄每個收集器的組態，部署新的代理程式，然後重新建立或移動收集器。 
|===


[[before-you-begin]]
== 開始之前

* 以 Data Infrastructure Insights 系統管理員或帳戶擁有者身分登入。刪除代理程式需要系統管理員權限。
* 按名稱識別代理程式，並在代理程式詳細資料頁面上審查指派給它的收集器。
* 請儲存您仍然需要的任何採集器組態。已刪除的採集器組態無法恢復。
* 從任何參照它的警報原則中移除指派給此代理程式的每個收集器。仍被警報原則參照的收集器會阻止刪除。


[cols="100%"]
|===
| *您無需暫停代理程式、取消固定它或等待升級* 暫停、恢復、固定和取消固定不會影響代理程式的刪除。已安排或正在進行的代理程式和收集器操作也不會區塊它。 
|===


[[choose-the-procedure-that-matches-your-agent]]
== 選擇與您的代理程式相符的程序

代理程式清單顯示每個代理程式的狀態。刪除之前必須執行的操作取決於代理程式是否仍然連線。

[cols="21%,62%,17%"]
|===
| *代理程式狀態* | *Workload Security 需要什麼* | *使用* 


| 已連接 | 必須先從代理程式中移除所有資料收集器和 User Directory Collector。收集器的狀態無關緊要；已停止的收集器仍會列入計算。 | 程序 A 


| 未連接 | 無需先移除收集器。任何仍已指派的收集器都會與代理程式一起刪除。 | 程序 B 
|===


[[procedure-a-delete-a-connected-agent]]
== 程序 A：刪除已連線的代理程式

*1.*選擇 Workload Security ++>++ 收集器 ++>++ 代理程式，然後選擇代理程式名稱以開啟其詳細資訊。

*2.*移動或刪除代理程式上列出的所有資料收集器。若要繼續收集相同的儲存設備，請將收集器指派給另一個代理程式，而不是將其刪除。

*3.*移動或刪除代理程式列出的所有使用者目錄收集器。

*4.*返回 Workload Security ++>++ 收集器 ++>++ 代理程式。

*5.*選擇代理程式的選項選單，然後選擇「刪除」。

*6.*在「刪除代理程式」對話方塊中確認刪除。

*7.*依照「解除安裝代理程式軟體」中的說明，在其主機上解除安裝代理程式軟體。

image:ws-delete-agent-confirmation.png["刪除代理程式對話方塊確認刪除範例代理程式，並顯示從其主機解除安裝代理程式軟體的命令。,title=\"刪除代理程式確認對話方塊\",width=1007,height=562"]

[cols="100%"]
|===
| *如果對話方塊顯示「無法刪除代理程式」*，則表示至少有一個資料收集器或使用者目錄收集器仍指派給此已連線的代理程式。請移除剩餘的收集器，然後重試。如果您剛剛將其移除，請先重新整理代理程式頁面。 
|===


[[procedure-b-delete-a-retired-or-unreachable-agent]]
== 程序 B：刪除已停用或無法連線的代理程式

當代理程式主機正在停用或已經離線，且您不再需要指派給它的收集器時，請使用此程序。

*1.*請確認您不再需要指派給此代理程式的任何收集器。這些收集器將隨代理程式一起刪除。

*2.*如果主機仍然可連線，請依照「解除安裝代理程式軟體」中的說明解除安裝代理程式軟體。

*3.*選擇 Workload Security ++>++ 收集器 ++>++ 代理程式，然後等待代理程式顯示「未連線」。

*4.*選擇代理程式的選項選單，然後選擇「刪除」。

*5.*在「刪除代理程式」對話方塊中確認刪除。



[[uninstall-the-agent-software]]
== 解除安裝代理程式軟體

在 Workload Security 中刪除代理程式會移除其雲端組態。它不會從主機解除安裝軟體，因此在停用主機時，請單獨解除安裝該軟體。

*1.*在代理程式主機上開啟終端工作階段。

*2.*執行解除安裝命令，並在出現提示時輸入 y。

[listing]
----
sudo cloudsecure-agent-uninstall.sh
----
解除安裝程式會停止並停用代理程式服務，並移除安裝目錄。若要解除安裝時不顯示確認提示，請新增 -n 選項。



[[verify-the-deletion]]
== 驗證刪除操作

* 代理程式不再出現在 Workload Security ++>++ 收集器 ++>++ 代理程式中。
* 分配給它的收集器不再出現在收集器清單中。
* 如果您解除安裝了該軟體，則主機上將不再存在代理程式服務。




[[troubleshooting]]
== 故障排除

[cols="39%,61%"]
|===
| *訊息或症狀* | *原因及解決方法* 


| 無法刪除代理程式：「請刪除在 ++<++Agent++>++ 上設定的所有資料收集器。」 | 代理程式已連線，且仍指派了至少一個資料收集器或使用者目錄收集器。請移動或刪除剩餘的收集器，重新整理頁面，然後重試。 


| "在刪除代理程式之前，請先從這些原則中移除該代理程式的下列裝置。" | 此代理程式下的收集器仍被訊息中指定的警報原則引用。請編輯每個原則，移除該收集器，儲存原則，然後重試刪除。 


| 刪除操作因授權錯誤而失敗。 | 刪除代理程式需要系統管理員或帳戶擁有者。其他角色可以開啟代理程式頁面，但無法完成刪除。 


| 代理程式回報為未註冊。 | 代理程式已被刪除，或您正在其他環境中操作。請重新整理代理程式頁面並確認代理程式和租戶。 


| 代理程式已從 Workload Security 中移除，但仍在主機上執行。 | 刪除代理程式並不會解除安裝軟體。請在主機上執行解除安裝命令。 


| 已刪除的收集器似乎仍然會使用使用量。 | 使用情況是由每個報告週期內存在的收集器所報告。請刪除不再使用的代理程式和收集器，並移動收集器而非重新建立它們，以免新舊收集器重疊。 
|===
